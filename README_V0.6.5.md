# TaiwanV2Scanner V0.6.6

本版以 V0.6.4 BUILD FIX 為基準，新增：
- 狀態區改為可隨內容高度成長，避免「設定已儲存」等長訊息遮住內容。
- 排程模式：交易時段模式（平日 09:00～13:30）／測試模式（不限交易時段）。
- 交易時段模式在非交易時段只記錄 skip，不啟動掃描；測試模式可在非盤中時間執行。
- 成功掃描後額外上傳 `scanner_data/Raster_TWSE.json` 與 `scanner_data/Raster_TPEX.json`，讓外部讀取端可分別取得上市／上櫃資料。
- 原有 `latest.json`、history/failed/test 與 GitHub Token 流程保留。

注意：本版「交易時段模式」目前判斷為週一至週五 09:00～13:30；尚未接入正式台股休市日曆 API，因此國定假日仍可能需要進一步補上交易日曆判斷。


V0.6.6 變更：排程交易模式先以少量 MIS 行情做市場狀態預檢；最新與歷史資料均按 TWSE/TPEX 分檔，避免單一大檔。
