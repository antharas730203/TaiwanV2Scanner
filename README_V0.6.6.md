# TaiwanV2Scanner V0.6.6

本版依 2026-08-31 討論定案：

- 排程「交易時段模式」觸發後，先用少量 MIS 行情做市場狀態預檢，再決定是否進入完整掃描。
- 09:00 前、13:30 後直接跳過；盤中則先取 TWSE 2330 + TPEX 6488 少量資料。
- 預檢 API 無法確認或無行情回應時，交易模式採 fail-closed，不啟動完整掃描。
- 「測試模式」保留，可繞過交易日／盤中限制。
- 完整掃描維持動態上市／上櫃筆數、150 檔基準與自動降批。
- GitHub 最新資料拆成 `scanner_data/latest_TWSE.json` 與 `scanner_data/latest_TPEX.json`。
- 每次歷史資料也依市場拆分，例如 `scanner_data/history/20260831_100500_TWSE.json` 與 `_TPEX.json`。
- 不再產生單一 1.4MB 的歷史檔。
- 不主動刪除行情欄位；待實際分析累積後，再依欄位使用頻率評估精簡。
- UI 狀態區維持多行顯示，並增加市場預檢診斷資訊。
